# Guía de Uso del Proyecto: Laboratorio 03

Bienvenido a la documentación de este proyecto.

## Descripción General

Este proyecto consiste en el desarrollo práctico de un laboratorio 04 del curso.

### Requisitos Previos

Antes de comenzar, asegúrate de tener instalado en tu computadora:
* Un editor de código profesional.
* Git instalado y configurado globalmente en tu sistema operativo.
* Un navegador web para renderizar el proyecto.

## Instalación y Uso

Pasos para clonar el repositorio y ejecutar el proyecto en tu máquina:

1. Abre tu terminal o consola de comandos local.
2. Clona este repositorio ejecutando el comando `git clone` seguido de la URL de tu proyecto.
3. Navega dentro de la carpeta del proyecto usando el comando `cd MI_portafolio`.
4. Abre el archivo principal en tu editor de código.

### Ejemplo de Configuración Git

Para verificar el estado de tus archivos antes de guardar cualquier progreso, puedes ejecutar el comando `git status` en tu terminal en cualquier momento.

El flujo de trabajo estándar utilizado en este laboratorio se compone del siguiente bloque de comandos:

```
git add .
git commit -m "Mensaje descriptivo del cambio"
git push origin main
```
